# Semantic surface conformance

Specification for `jcpe-semantic-surface-conformance-32w2.1`. This packet does
not certify an engine, its adoption by the studio, or Apple execution.

The consumer is the existing cross-surface build/proof package and Q0/R0. The
observed failures are concrete: the studio and native bridge invoke different
continuation engines; the studio reports complete major-scale containment from
a maximum-overlap vote; and engine tasks were closed using tests that never
invoked the promised production operations. Retire this packet only when a
successor preserves those obligations and the original packages' musical laws.

## Authority and dispatch

The operation inventory covers H0, H1 and G0–G9 public semantic entry points,
their operation-object helpers, and the narrower chart/continuation entry
points used by the current studio. A helper is not another completed feature.
Source presence is an observation, never a passing musical result. At the
86aee23 baseline, `deriveLiteralFacts` exists and is exported; the studio still
calls `analyzeChartEvent`/`deriveChordDetail`. H0's context and scale operations
remain required even when a narrower view is useful.

Each adopted query must be invoked through its actual application owner or
native bridge. Record the invoked operation, engine/version, source request,
selected realizations, rule/corpus/policy versions, measured result and exact
expected/observed musical differences. This diagnostic record is not Apply
authority. A renamed import, expected function name in JSON, fabricated
dispatch receipt, or adapter that calls the engine and discards its result
cannot establish adoption. Plant absent, no-op, wrong-engine and altered-result
faults at the actual dispatch seam; semantic assertions must reject them.

UI renders application selectors and dispatches intents. It never directly
calls theory, audio, storage, or download services. Theory remains pure, imports
only domain, and receives corpus operations through injected interfaces.
Synchronous H0/V0/V1 calls retain their accepted applicability limits; wrapping
them does not prove cancellation inside a synchronous call. Discovery queries
and publication use the completed shared execution service, including its
actual managed arena, latest-source binding, yielded work and A0 registry.

All fifteen web capabilities remain in scope through their original owning
engine/UI packages. This packet does not duplicate their implementations,
replace their independent full law inventories, or approve their existing
fixtures merely by hashing them. A missing law proof remains a missing gate.
G1's compiler/query/fingerprint proof uses its independently authored small
corpus; D0 retains the separate 250-reviewed-seed/3,000-variant requirement.

## What a source binding includes

Capture document identity/revision, exact event identity/order/absolute rational
position/duration, full chord spelling and annotation, selected realization,
Manual/Frozen pitches with order and duplicate unisons, and the complete
engine/policy/law/corpus/seed envelope. Selection changes invalidate cached
context even when the document reference does not change. Never skip a custom
or unsupported event and pretend the parsed chords on either side are adjacent.
Preserve the event as an explicit barrier or return a typed unavailable reading.

Distinguish literal facts, contextual readings and optional transformations.
No numeric vote becomes a probability, complete containment, or a persisted key.
Missing key/neighbor/realization evidence stays visible; an absent selection
among multiple altered realizations must not silently choose index zero.
Exact spellings and enharmonic pitch classes are separate observations.

## Major-context containment regression

The current studio sentence says that `Cmaj7, Bm7#5, Ebmaj7, E7#9` sit inside
C major. Independent degree arithmetic gives 17 chord-tone occurrences. Only 14
pitch classes fit C major; Eb, Bb and G# are outside. The two written F-double-
sharps also differ from the scale's written G, despite equal pitch class.
C and G major tie on the pitch-class vote. Neither is complete containment,
nor does that tie establish a tonal center. The fixture distinguishes exact
spelling agreement, pitch-class overlap, counterevidence and tied hypotheses.

Keep useful candidates while making their actual support inspectable. A
diatonic candidate may be described as a chord available under an explicitly
named major-key reading. “All these chords fit” requires complete observed
containment under the named interpretation; a softer confidence adjective
cannot rescue a false hard assertion. A selected altered realization must
change the observed evidence when its notes change. No-key, ties, custom
barriers, chromatic near misses and all twelve pitch-class transpositions are
mandatory, alongside independent spelling-boundary cases.

The source regression and actual starter-chart browser journey must both pass.
Testing only `generateContextualContinuations` cannot certify the existing
`deriveContinuationSuggestions` path. The build may replace or explicitly
adapt that path only while preserving useful legitimate behavior and proving
the actual output shown to the musician.

## Native scope and versioning

First-release native parity covers G2 continuation only. Native G0/G1/G3–G9
workbenches are outside this package's native scope. Source replay of the
generated bridge on Linux proves JavaScript semantics and byte closure only;
real JavaScriptCore/AVAudioEngine execution belongs to the existing Apple
DSR/Xcode lane. A missing Apple host is an unexecuted gate. Never automate
audible Simulator playback or claim human listening from generated samples.

The existing native v1 bridge accepts symbols only, invents local IDs and
four-beat coordinates, projects eight suggestions, and omits source revision
from the response. It cannot establish exact timed-source or stale-response
parity. The Swift store already tags options with its local revision and
refuses stale application; preserve that useful guard. A locally attached
revision is distinct from a source binding returned by the bridge itself.
A versioned exact-source adapter must carry the real binding and return
the same identity, checked engine versions, pitches/spellings, exact timing,
refusals and evidence as the web adapter for the same request and policy.
The old symbol-only endpoint must not masquerade as this new authority.
Preserve compatibility through an explicit limited endpoint or typed version
refusal; never silently upgrade a v1 request by inventing omitted data.

Native context remains at most 8 events, its input at most 16,384 UTF-16 code
units, and displayed options at most 8. Web G2 retains 8 context events,
32 candidates/provider and 16 displayed options. Compare native/web semantics
under the same explicit eight-option projection; also prove the web's full
sixteen-option limit independently. Display projection cannot alter the
underlying semantic request, ranking, constraints or measured work.

## Real musician journey

Use the production standalone studio and real visible actions to enter a
bar-delimited chart, inspect literal/plural context, preview without mutation,
edit during search, reject the stale result, recompute, Apply once and Undo
the exact document and bookmarks. Then restart through actual recovery and
download canonical JSON, chart text and MIDI through their real adapters.

The immutable playback plan is the audio/MIDI oracle. Compare actual emitted
MIDI events, tick durations, pitches and timing to that same plan; an MThd
header or a button count is insufficient. Canonical export advances its marker
only on successful exact delivery. Text/MIDI disclose their defined losses and
never advance the canonical marker. Preview/search stay nonmutating; Apply
retires both progression and preview and makes exactly one A0 transaction.

The journey corpus includes odd meter/pickup, empty/partial bars, unsupported
and custom chords, multiple altered realizations, double-accidental boundaries,
sixteen stored voices with duplicate unisons, stale IDs/revisions/selections,
storage denial/quota/corruption with real fallback, cancellation at every yield
and awaited retirement, and exact Undo/Redo/replacement/recovery identity.
Run desktop/phone, keyboard/touch, zoom and reduced motion with the actual
product styles, offline resources and existing accessibility gates.

Do not duplicate or waive the existing U2/U4/U5/U7 implementations or their
acceptance. A smaller generic harness is useful upstream evidence, but cannot
replace this production journey.

## Limits and verification

The shared execution contract supplies the common 256-source-event,
4 MiB request, 8 MiB result/snapshot, 64 MiB managed ownership and deterministic
work/candidate/state/depth bounds. Every original engine's stricter limits
still apply, including G0's five alternatives, G3's eight events/64 outgoing/
50,000 states, G4's 16 slots/128 candidates per slot/100,000 states and G5's
depth 3/width 8/128 nodes. Do not clamp requests or truncate results silently.
Wall time is performance evidence, never a musical termination condition.

The specification gate is `bun scripts/validate-semantic-surface-conformance-contract.ts`,
`bun test tests/static/semantic-surface-conformance-contract.test.ts` and full
`bun run typecheck`. Static checks replay independent arithmetic, malformed
packets, source/trace closure and planted fixture mutations; they do not call
production engines to manufacture expected music.

The later `scripts/verify-semantic-surface-conformance-evidence.ts` must run its
named production suites and `tests/e2e/semantic-surface-conformance.spec.ts`
through supported real Node with zero retries/skips/todos/only/quarantine.
Bind all declared inputs before/after, actual artifact/bridge bytes, seeds,
versions, requests, every expected/observed semantic difference, timing samples,
voice/listener/port/memory counts, storage outcomes and downloaded bytes.
Inspect every required row and fail missing/duplicate/incorrect observations;
write `test-results/semantic-surface-conformance-evidence.json`. Integrate the
real contract/evidence commands into existing aggregate verification only when
their production wiring exists. Package closure still requires all three
phases, while Q0/R0 retain aggregate, human, Apple and deployment gates.
